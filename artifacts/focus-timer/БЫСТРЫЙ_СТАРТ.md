# ⚡ Быстрый Старт - Настройка timero.ru

## 🎯 Что нужно сделать СЕЙЧАС

### 1️⃣ Настроить DNS на reg.ru (5 минут)

Зайдите в панель управления доменом на reg.ru:

**Для timero.ru:**
```
Тип: A
Хост: @ (или пусто)
Значение: 216.198.79.1
```

**Для www.timero.ru:**
```
Тип: CNAME
Хост: www
Значение: e4bad6fce63536d5.vercel-dns-017.com.
```

💡 **Как это сделать:**
- Выберите "Подключение домена к хостингу или сервису"
- Для основного домена выберите "IP-адрес" → введите `216.198.79.1`
- Для www добавьте CNAME запись

⏱️ **Ожидание:** 10-30 минут (максимум 24 часа)

---

### 2️⃣ Заменить ID Аналитики (2 минуты)

Откройте файл `index.html` и замените:

**Yandex.Metrika:**
```javascript
// Найдите эту строку:
ym(98765432, "init", {

// Замените 98765432 на ваш ID с https://metrika.yandex.ru/
```

**Google Analytics:**
```javascript
// Найдите эти строки:
gtag/js?id=G-XXXXXXXXXX
gtag('config', 'G-XXXXXXXXXX');

// Замените G-XXXXXXXXXX на ваш ID с https://analytics.google.com/
```

---

### 3️⃣ Задеплоить на Vercel (1 минута)

```bash
git add .
git commit -m "Setup timero.ru domain and analytics"
git push origin main
```

Vercel автоматически задеплоит изменения.

## 🆘 Проблемы?

### Домен не работает:
- Подождите 24 часа для DNS пропагации
- Проверьте: https://dnschecker.org/
- Очистите кэш браузера (Ctrl+Shift+Delete)

### Favicon не видно:
- Очистите кэш браузера
- Проверьте: https://timero.ru/favicon-32x32.png

### Аналитика не работает:
- Проверьте, что заменили ID на реальные
- Отключите AdBlock
- Подождите 5-10 минут
