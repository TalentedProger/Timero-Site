# Чек-лист для тестирования UI улучшений

## Быстрый старт

```bash
cd artifacts/focus-timer
npm install
npm run dev
```

Откройте http://localhost:5173 в браузере

---

## 1. Проверка цветовой схемы ⚫

### Левая панель (Appearance)
- [ ] Откройте левую панель (иконка палитры снизу)
- [ ] **Фон**: Должен быть чисто черный с полупрозрачностью
- [ ] **Blur**: Должен быть умеренным (не слишком сильный)
- [ ] **Заголовки**: "BACKGROUND", "DIMMING", "SOUND" и др. - все белые

### Правая панель (Activity)
- [ ] Откройте правую панель (иконка графика снизу)
- [ ] **Фон**: Чисто черный с полупрозрачностью
- [ ] **Blur**: Умеренный
- [ ] **Заголовки**: "STATISTICS", "RECENT SESSIONS" - белые

### Нижняя навигация
- [ ] Проверьте нижнюю панель с иконками
- [ ] **Фон**: Черный с легкой полупрозрачностью
- [ ] **Blur**: Легкое размытие

### Галерея фонов
- [ ] Откройте левую панель → "All Backgrounds"
- [ ] **Фон**: Почти черный (96% непрозрачность)
- [ ] **Заголовок**: "ALL BACKGROUNDS" - белый

- [ ] Откройте секцию "SOUND"

## 4. Проверка анимации полноэкранного режима 🎬

### Desktop (широкий экран)
- [ ] Нажмите иконку полноэкранного режима (снизу)
- [ ] **Проверьте плавность**:
  - ✅ Фон появляется плавно
  - ✅ Таймер плавно масштабируется и появляется
  - ✅ Левая кнопка (стрелка) выезжает слева
  - ✅ Правая кнопка (play/pause) выезжает справа
  - ✅ Текст подсказки снизу появляется последним
- [ ] **Нет рывков** при открытии
- [ ] Все элементы появляются поочередно (staggered)
- [ ] Нажмите ESC или кликните для выхода - плавное закрытие

### Mobile (узкий экран или DevTools mobile mode)
- [ ] Откройте DevTools → Toggle device toolbar (Ctrl+Shift+M)
- [ ] Выберите iPhone или Android устройство
- [ ] Откройте полноэкранный режим
- [ ] **Анимация должна быть быстрее** чем на desktop
- [ ] Все элементы появляются почти одновременно
- [ ] Нет задержек и лагов

## Известные особенности

### ✅ Это нормально:
- Hover эффекты не работают на мобильных (оптимизация)
- Анимации быстрее на мобильных (лучшая производительность)
- Фоны загружаются фоном (не замедляют сайт)
- RequestIdleCallback может не работать в старых браузерах (есть fallback)

### ❌ Если это происходит - это баг:
- Текст остается на русском при выборе другого языка
- Панели имеют синеватый оттенок
- Blur слишком сильный
- Видно "Время проигрывания (сек)"
- Анимации рывками
- Console ошибки
