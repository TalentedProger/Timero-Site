# ⚡ Быстрый старт - Premium Focus Timer

## 🚀 Деплой за 5 минут

### Шаг 1: Установка зависимостей
```bash
npm install
```

### Шаг 2: Проверка сборки
```bash
npm run build
```

### Шаг 3: Git
```bash
git init
git add .
git commit -m "Ready for production"
```

### Шаг 4: GitHub
1. Создайте репозиторий на GitHub
2. Подключите и запушьте:
```bash
git remote add origin https://github.com/YOUR_USERNAME/premium-focus-timer.git
git push -u origin main
```

### Шаг 5: Vercel
1. Зайдите на [vercel.com](https://vercel.com)
2. Нажмите "New Project"
3. Импортируйте репозиторий
4. Настройки:
   - Framework: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. Нажмите **Deploy**

## ✅ Готово!

Ваш сайт будет доступен через 2-3 минуты по адресу:
`https://your-project.vercel.app`
