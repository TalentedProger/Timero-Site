## 🤖 robots.txt

### ✅ Оптимизация:

```
# Разрешено для всех
User-agent: *
Allow: /

# Запрещено
Disallow: /api/
Disallow: /*.json$
Disallow: /admin/
Disallow: /private/

# Sitemap
Sitemap: https://timero.ru/sitemap.xml

# Crawl-delay
Crawl-delay: 1

# Яндекс
User-agent: Yandex
Allow: /
Crawl-delay: 1

# Блокировка плохих ботов
User-agent: AhrefsBot
Disallow: /
```

**Особенности:**
- Явное разрешение для Яндекс и Google
- Блокировка SEO-ботов (экономия ресурсов)
- Crawl-delay для уважительного краулинга
