# 🔧 Исправление Vercel деплоя для монорепозитория

## ❌ Проблема

Vercel пытался собрать весь pnpm workspace монорепозиторий вместо конкретного проекта `artifacts/focus-timer`:

```
Detected `pnpm-lock.yaml` 9 which may be generated by pnpm@9.x or pnpm@10.x
Using pnpm@10.x based on project creation date
Running "install" command: `npm install --force --no-optional`...
npm warn Unknown project config "auto-install-peers"
npm warn Unknown project config "strict-peer-dependencies"
> workspace@0.0.0 build
> pnpm run typecheck && pnpm -r --if-present run build
```

## 🔍 Причина

1. **Монорепозиторий**: Репозиторий `Timero-Site` - это pnpm workspace с несколькими проектами
2. **Неправильный Root Directory**: Vercel собирал корень вместо `artifacts/focus-timer`
3. **pnpm-специфичные настройки**: В корневом `.npmrc` были настройки для pnpm
4. **Windows-специфичные devDependencies**: В корневом `package.json` были Windows-пакеты

## ✅ Решение

### 1. Создан `vercel.json` в корне репозитория

```json
{
  "buildCommand": "cd artifacts/focus-timer && npm run build",
  "outputDirectory": "artifacts/focus-timer/dist",
  "installCommand": "cd artifacts/focus-timer && npm install --include=dev --no-optional",
  "ignoreCommand": "git diff --quiet HEAD^ HEAD ./artifacts/focus-timer"
}
```

**Что это делает:**
- `buildCommand` - переходит в `artifacts/focus-timer` и собирает проект
- `outputDirectory` - указывает путь к dist папке внутри монорепозитория
- `installCommand` - устанавливает зависимости с devDependencies, но без optional
  - `--include=dev` - явно включает devDependencies (нужно для Tailwind, Vite, TypeScript)
  - `--no-optional` - пропускает optional dependencies (платформо-зависимые пакеты)
- `ignoreCommand` - деплоит только если были изменения в `artifacts/focus-timer`

### 2. Обновлен корневой `.npmrc`

Удалены pnpm-специфичные настройки, добавлены npm-совместимые:

```
# npm configuration for Vercel deployment
# Ignore platform-specific optional dependencies
optional=true

# Engine strict mode - allow installation even if engines don't match
engine-strict=false
```

### 3. Обновлен корневой `package.json`

Удалены Windows-специфичные devDependencies:

```json
{
  "devDependencies": {
    "prettier": "^3.8.1",
    "typescript": "~5.9.2"
  }
}
```

Удалены:
- `@rollup/rollup-win32-x64-msvc`
- `lightningcss-win32-x64-msvc`

## 📋 Что было сделано

```bash
# Созданы/обновлены файлы в корне репозитория
git add vercel.json .npmrc package.json
git commit -m "Fix: Configure Vercel for monorepo deployment (focus-timer)"
git push origin main
```

## 🎯 Результат

После этих изменений Vercel:
- ✅ Собирает только `artifacts/focus-timer`
- ✅ Использует npm вместо pnpm
- ✅ Не пытается установить Windows-специфичные пакеты
- ✅ Не выдает предупреждения о pnpm-специфичных настройках
- ✅ Деплоит только при изменениях в `artifacts/focus-timer`

## 📚 Структура репозитория

```
Timero-Site/ (корень репозитория)
├── .npmrc                          # npm конфигурация для Vercel
├── package.json                    # Корневой package.json (workspace)
├── pnpm-workspace.yaml             # pnpm workspace конфигурация
├── vercel.json                     # Vercel конфигурация для монорепозитория
└── artifacts/
    └── focus-timer/                # Проект для деплоя
        ├── .npmrc                  # npm конфигурация для focus-timer
        ├── package.json            # package.json проекта
        ├── vercel.json             # Vercel конфигурация проекта (не используется)
        ├── src/
        ├── public/
        └── dist/                   # Выходная папка сборки
```

## 🔗 Важные замечания

1. **Корневой `vercel.json` имеет приоритет** над `artifacts/focus-timer/vercel.json`
2. **Команды выполняются из корня репозитория**, поэтому нужен `cd artifacts/focus-timer`
3. **ignoreCommand** предотвращает ненужные деплои при изменениях в других частях монорепозитория
4. **pnpm-workspace.yaml остается** для локальной разработки на Replit

## 🚀 Следующие шаги

1. Откройте Vercel Dashboard
2. Выберите проект
3. Нажмите "Redeploy"
