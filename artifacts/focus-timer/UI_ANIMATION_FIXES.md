## 📋 Выполненные исправления

### 1. ✅ Убран glow эффект с выбранных фонов

**Файл:** `src/components/panels/BackgroundGallery.tsx`

**Проблема:** При выборе фона вокруг него появлялось сильное свечение (glow) с эффектом `boxShadow: 0 0 20px ${accent}44`

**Решение:** Удалён параметр `boxShadow` из стилей выбранных фонов (как Custom, так и обычных)

**Было:**
```tsx
style={{
  border: isSelected ? `2px solid ${accent}` : "...",
  boxShadow: isSelected ? `0 0 20px ${accent}44` : undefined,
}}
```

**Стало:**
```tsx
style={{
  border: isSelected ? `2px solid ${accent}` : "...",
}}
```

**Результат:** Выбранные фоны теперь имеют чистую фиолетовую рамку без свечения, как у кнопки "Сохранить"

### 2. ✅ Исправлено выравнивание иконок в главной кнопке Start/Pause

**Файл:** `src/components/timer/TimerControls.tsx`

**Проблема:** 
- Иконка Play имела `translate-x-1` (сдвиг на 4px), что нарушало центрирование
- Иконки могли "скакать" при переключении между Play и Pause

**Решение:**
- Удалён класс `translate-x-1` с иконки Play
- Добавлен inline style `marginLeft: '2px'` для точной оптической центровки треугольника Play
- Добавлен класс `shrink-0` к обеим иконкам для предотвращения сжатия

**Было:**
```tsx
<Play className="w-8 h-8 text-white fill-white translate-x-1" strokeWidth={0} />
```

**Стало:**
```tsx
<Play className="w-8 h-8 text-white fill-white shrink-0" strokeWidth={0} style={{ marginLeft: '2px' }} />
```

**Результат:** Иконки идеально выровнены по центру кнопки, нет визуальных скачков

### 3. ✅ Исправлены скачущие иконки в кнопках Reset и Set Time

**Файл:** `src/components/timer/TimerControls.tsx`

**Проблема:** При наведении на кнопки Reset и Set Time иконки внутри "скакали" из-за анимации scale

**Решение:** Добавлен класс `shrink-0` к иконкам RotateCcw и Timer

**Было:**
```tsx
<RotateCcw className="w-5 h-5 text-white/80" strokeWidth={2} />
<Timer className="w-5 h-5 text-white/80" strokeWidth={2} />
```

**Стало:**
```tsx
<RotateCcw className="w-5 h-5 text-white/80 shrink-0" strokeWidth={2} />
<Timer className="w-5 h-5 text-white/80 shrink-0" strokeWidth={2} />
```

**Результат:** Иконки остаются стабильными при hover эффектах, не скачут и не сжимаются

### 4. ✅ Исправлен размер кнопки dropdown "ШАБЛОНЫ"

**Файл:** `src/components/timer/TimePickerPanel.tsx`

**Проблема:** Была уменьшена иконка вместо контейнера

### 5. ✅ Оптимизированы анимации для максимальной плавности

**Новый файл:** `src/lib/animations.ts`

**Создан централизованный конфиг анимаций** с оптимизированными параметрами:

#### Типы анимаций:

1. **button** - для основных кнопок (Save, Close, Play/Pause):
   - hover: `scale: 1.05`, duration: `0.2s`, easing: `bounce [0.34, 1.56, 0.64, 1]`
   - tap: `scale: 0.95`, duration: `0.1s`

2. **smallButton** - для маленьких кнопок (Reset, Set Time):
   - hover: `scale: 1.08`, duration: `0.2s`, easing: `bounce [0.34, 1.56, 0.64, 1]`
   - tap: `scale: 0.92`, duration: `0.1s`

3. **card** - для карточек фонов:
   - hover: `scale: 1.02`, duration: `0.25s`, easing: `easeOut [0.16, 1, 0.3, 1]`
   - tap: `scale: 0.98`, duration: `0.15s`

4. **modal** - для панелей (TimePickerPanel):
   - initial: `opacity: 0, scale: 0.95, y: 20`
   - animate: `opacity: 1, scale: 1, y: 0`
   - transition: `spring` с `damping: 28, stiffness: 320`

5. **backdrop** - для затемнения фона:
   - duration: `0.25s`, easing: `easeOut`

6. **gallery** - для галереи фонов:
   - duration: `0.3s`, easing: `easeOut [0.16, 1, 0.3, 1]`

#### Easing функции:

- **easeOut** `[0.16, 1, 0.3, 1]` - плавный выход, для входов
- **bounce** `[0.34, 1.56, 0.64, 1]` - упругий эффект, для интерактивных элементов
- **easeInOut** `[0.65, 0, 0.35, 1]` - плавный вход-выход, для переходов

**Обновлённые компоненты:**
- ✅ `BackgroundGallery.tsx` - использует `animations.gallery`, `animations.button`, `animations.card`
- ✅ `TimerControls.tsx` - использует `animations.button`, `animations.smallButton`
- ✅ `TimePickerPanel.tsx` - использует `animations.modal`, `animations.backdrop`, `animations.spring`

**Результат:** 
- Все анимации теперь единообразные и оптимизированные
- Используются профессиональные cubic-bezier easing функции
- Длительность анимаций подобрана для максимального комфорта
- Spring анимации для модальных окон создают естественное ощущение
